# MVP 기획 초안

## 서비스 목적

사용 빈도가 낮은 특별한 날의 옷을 동네 이웃끼리 대여하여, 소유자는 옷을 활용하고 대여자는 구매 부담을 줄입니다.

## 핵심 기능

| 영역 | 초기 범위 |
| --- | --- |
| 회원 | 가입, 로그인, 프로필 |
| 동네 | 활동 동네 설정, 동네 기준 의류 탐색 |
| 의류 | 사진, 사이즈, 상태, 대여료, 가능 기간 등록 및 수정 |
| 대여 | 기간 선택, 요청, 수락·거절, 취소, 전달·반납 확인 |
| 채팅 | 전달 장소와 시간 협의 |
| 후기 | 완료된 대여에 대한 후기 |
| 알림 | 대여 요청 및 상태 변경 알림 |

## 기본 이용 흐름

1. 소유자가 의류 정보와 대여 가능 기간을 등록합니다.
2. 이웃이 동네와 조건으로 옷을 찾습니다.
3. 기간을 선택하고 대여를 요청합니다.
4. 소유자가 수락한 뒤 채팅으로 전달을 협의합니다.
5. 전달과 반납을 확인하고 후기를 남깁니다.

## 구현 전 결정할 정책

- 동네 인증 방법과 위치 공개 범위
- 대여 요금, 보증금, 결제 및 정산 방식
- 취소, 연체, 파손·분실, 세탁 책임
- 동일 의류의 기간 중복 예약 방지 및 예약 확정 시점
- 신고·차단과 분쟁 처리

위 항목은 확정된 운영 정책이 아니라 후속 설계 과제입니다. 결제, 관리자 기능 및 운영 정책은 결정 후 구조를 확장합니다.
