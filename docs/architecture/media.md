# 미디어 출처

토스 사이트의 넓은 영상 영역, 간결한 상단 탐색, 스크롤 중심 소개 방식을 참고했습니다. 토스의 로고, 카피, 영상, 코드 및 이미지는 사용하지 않았습니다.

## 이미지

Unsplash의 공개 이미지 URL에서 가져와 로컬 파일로 포함했습니다. 상품명, 가격, 동네는 서비스 체험을 위한 예시 데이터입니다.

## 영상

brand-film.mp4는 hero.jpg에 부드러운 줌 움직임을 적용한 20초 무음 모션 영상입니다. H.264, 1440×900, 30fps, faststart로 인코딩했습니다. 별도의 실사 촬영 영상은 아닙니다. 외부 영상 서비스 연결 없이 재생되며 재생 실패 시 포스터를 유지합니다.
